# AtCoder 習得ログ：C++ 基礎編

## 1. 型の演算と連結
C++では、型の組み合わせによって挙動が変わるため注意が必要。

| 組み合わせ | 挙動 | 備考 |
| :--- | :--- | :--- |
| `char` + `char` | **数値計算** | 文字コード（ASCII）としての足し算になる |
| `char` + `string` | **連結** | 文字列の末尾に文字が追加される |
| `string` + `string` | **連結** | 文字列同士がつながる |

## 2. ループの制御 (`break`)
* **二重ループの注意点**: `break` は **現在実行中のループ（一番内側）** しか抜けない。
* 外側のループまで一気に抜けたい場合は、フラグ（`bool`）を使うか、関数にして `return` するのが一般的。

## 3. 二次元配列 (`vector<vector<T>>`)
2次元配列は「配列の配列」という構造であることを意識する。

* **行数（タテ）**: `vec.size()`
* **列数（ヨコ）**: `vec[0].size()` （0番目の行に含まれる要素数）
* **アクセス**: `vec[i][j]` （i行目のj列目）

## 4. 表形式の出力（改行と空白の制御）
行末に余計な空白を入れないための実装パターン。競技プログラミングの出力形式指定で多用する。

```cpp
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        cout << table[i][j];

        if (j == N - 1) {
            cout << endl; // 行末なら改行
        } else {
            cout << " ";  // 要素間なら空白を入れる
        }
    }
}
